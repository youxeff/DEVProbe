# DevProbe

DevProbe is an AI-assisted code review and CI quality platform.

## Planned Features
- Connect to GitHub repositories
- Analyze pull requests
- Detect security, lint, complexity, and test coverage issues
- Generate AI-assisted review summaries
- Store scan history
- Display code quality dashboards

## Tech Stack
- Next.js
- TypeScript
- FastAPI
- PostgreSQL
- SQLAlchemy
- GitHub API
- OpenAI API
- Docker
